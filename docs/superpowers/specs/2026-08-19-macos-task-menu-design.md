# TempoTasks macOS 菜单栏任务管理器设计规格

## 1. 目标

TempoTasks 是一个仅驻留在 macOS 菜单栏的轻量任务管理器。用户按 `Control + Space` 唤出悬浮面板，在同一界面中选择日期、录入任务、勾选完成和删除任务。

首版的成功标准：

- 从任意应用按 `Control + Space` 后，任务面板出现且输入框获得焦点。
- 用户不离开键盘即可输入任务并按回车保存。
- 用户可以在“今天”“明天”和任意指定日期之间切换。
- 勾选任务后，整行立即显示删除线并置灰；再次勾选可恢复。
- 重启应用后，任务及完成状态仍然存在。

## 2. 范围

### 包含

- macOS 菜单栏入口。
- `Control + Space` 全局快捷键。
- 悬浮任务面板。
- 快速添加任务。
- 今天、明天和系统日期选择器。
- 按日期查看任务。
- 完成、恢复、删除和撤销删除。
- 本地持久化。

### 不包含

- Apple 日历或提醒事项同步。
- 提醒通知、具体时间、重复任务。
- 账号、云同步、共享、项目、标签和优先级。
- iOS 版本或桌面小组件。

## 3. 视觉方向

采用用户确认的 B「深色指令台」：

- 近黑蓝背景 `#070A10`，不使用纯黑。
- 主文字为近白色，次要文字为冷灰色。
- 蓝色仅用于焦点和当前日期；珊瑚红仅用于完成勾选和少量强调。
- 左侧为窄日期轨道，右侧为快速输入和高密度任务列表。
- 系统无衬线字体负责中文和正文，等宽字体仅用于日期数字与快捷键。
- 使用细边框、内外双层阴影和小圆角表达 macOS 工具感；不使用紫色渐变、霓虹或装饰性动画。
- 动效只用于面板出现、勾选和撤销提示，时长不超过 200ms，并支持减少动态效果设置。

设计拨盘：视觉冒险度 4/10，动效强度 3/10，信息密度 6/10。

## 4. 主交互流程

### 4.1 唤出与隐藏

1. 应用启动后在菜单栏显示任务图标，不出现在 Dock。
2. 用户按 `Control + Space`，或左键点击菜单栏图标，面板出现在当前屏幕顶部中央。
3. 面板打开时输入框自动获得焦点。
4. 再次按 `Control + Space`、按 `Escape` 或点击面板外部，面板隐藏。
5. 隐藏不会退出应用；未按回车提交的草稿在本次应用运行期间保留，正常退出后不持久化草稿。
6. 右键点击菜单栏图标打开菜单，显示快捷键状态、“打开 TempoTasks”和“退出 TempoTasks”。

全局快捷键使用 Carbon `RegisterEventHotKey`，不要求辅助功能权限。注册失败时，菜单栏菜单显示“快捷键不可用”，点击菜单栏图标仍可打开面板。

### 4.2 日期选择

- 左侧轨道固定显示今天和明天。
- 第三个入口显示最近一次选择的其他日期；首次使用时显示“选择日期”。
- 点击第三个入口打开系统日期选择弹层。
- 切换日期会同时改变任务筛选结果和新任务默认日期。
- 日期使用不带时间和时区的 `LocalDay(year, month, day)` 公历日语义；选择时从用户当前时区取公历年月日，存储后不会因时区变化而改变日历日。
- 应用首次启动及每次重新启动时默认选中“今天”。
- 当前选择使用 `.today`、`.tomorrow`、`.custom(LocalDay)` 三种语义状态，而不是只保存一个绝对时间点。
- 应用收到系统跨日通知、时区变化通知或每次显示面板前，会重新计算今天和明天；选择 `.today` 或 `.tomorrow` 时筛选自动跟随新日期，选择自定义日期时保持原日历日。
- 如果日期选择器选中今天或明天，选择状态切换到对应固定入口；第三个入口继续保留最近一次真正的自定义日期，不重复显示今天或明天。

### 4.3 快速添加

- 面板打开后，光标位于任务输入框。
- 输入非空文本并按回车后立即创建任务，日期取当前选中日期。
- 首尾空白会被移除；纯空白内容不会创建任务。
- 标题最多 500 个用户可感知字符，以 Swift `String.count`（扩展字形簇）为准。超过上限时不创建、不截断，保留草稿和输入焦点，并在输入框下方显示“任务不能超过 500 个字符”。
- 成功后输入框清空并保持焦点，不显示常驻成功信息。
- 允许创建同名任务。

### 4.4 任务列表

- 当前日期的未完成任务按创建时间从早到晚排列。
- 已完成任务排列在未完成任务之后，并按完成时间从新到旧排列。
- 每行左侧是 checkbox，中间是可换行的任务标题，右侧在悬停时显示删除按钮。
- 标题最长 500 个字符；超长标题换行，最多显示三行，完整内容可通过辅助功能读取。
- 无任务时显示与当前筛选匹配的简短空状态：“今天还没有任务”“明天还没有任务”或“8 月 21 日还没有任务”；输入框仍然是视觉主操作。
- 排序的最终次级键为 `id.uuidString`，确保创建时间或完成时间相同的任务仍有稳定顺序。

### 4.5 完成与恢复

- 点击 checkbox 后立即切换完成状态并保存。
- 完成状态：整行文字置灰、任务标题增加删除线、checkbox 使用珊瑚红填充。
- 再次点击恢复为未完成状态，并回到未完成分组。
- 保存失败时恢复原状态，并在列表底部显示带“重试”操作的错误提示。

### 4.6 删除与撤销

- 删除属于低影响操作，不弹确认框。
- 点击删除后任务立即从列表消失，并显示 5 秒“已删除任务 · 撤销”提示。
- 点击撤销会恢复删除前的完整快照，包括原 `id`、标题、日期、完成状态、`createdAt` 和 `completedAt`，因此排序不会变化。
- 超过 5 秒后撤销入口消失。应用退出前已经完成的数据保存保持有效。
- 撤销控制器只维护最近一次删除。若 5 秒内再次删除，前一条删除立即失去撤销资格，新提示只对应最近删除的任务。

## 5. 窗口与组件

### 悬浮面板

- 默认尺寸 760 × 520 pt；内容超出时只滚动任务列表。
- 使用自定义 `NSPanel`，层级为 `.floating`，可在所有 Spaces 出现。
- 面板采用顶部居中定位，并限制在当前屏幕可见区域内。
- 支持键盘焦点、VoiceOver 标签和高对比度焦点环。

### 组件边界

- `AppDelegate`：管理应用生命周期和菜单栏入口。
- `GlobalHotKeyRegistrar`：注册、注销并上报快捷键状态。
- `PanelController`：创建、定位、显示和隐藏 `NSPanel`，不处理任务数据。
- `TaskRepository`：封装 SwiftData 的查询和增删改，向界面暴露明确操作结果。最小接口为 `fetchTasks(on: LocalDay)`、`create(title:dueDay:)`、`setCompleted(_:completed:)`、`delete(_:)` 和 `restore(snapshot:)`；所有操作均可抛出错误。
- `TaskPanelView`：组合日期轨道、输入区、任务列表和反馈区域。
- `DateRailView`：维护当前选中日期并打开系统日期选择器。
- `QuickAddView`：维护草稿、校验和提交动作。
- `TaskListView` / `TaskRowView`：展示、完成、恢复和删除交互。
- `UndoDeleteController`：保存最近一次删除快照及 5 秒撤销窗口。

组件之间通过初始化参数、Observable 状态和小型协议通信，不直接读取彼此内部状态。

## 6. 数据模型与数据流

SwiftData 模型 `TaskItem`：

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | UUID | 稳定主键 |
| `title` | String | 去除首尾空白后的标题，最多 500 字符 |
| `dueYear` | Int | 不带时区的公历年份 |
| `dueMonth` | Int | 不带时区的公历月份 |
| `dueDay` | Int | 不带时区的公历日 |
| `isCompleted` | Bool | 当前完成状态 |
| `createdAt` | Date | 创建时间 |
| `completedAt` | Date? | 最近完成时间；恢复后清空 |

数据流：用户操作 → View 调用 Repository → SwiftData 保存 → Repository 返回成功或错误 → View 刷新或恢复先前状态。

所有本地数据写入都在主 actor 上串行执行。首版没有网络请求、后台同步或多端冲突。

`LocalDay` 是独立值类型，包含公历 `year`、`month`、`day`。`today` 和 `tomorrow` 在每次面板显示、跨日或时区变化时，由固定公历和系统当前时区重新计算；自定义日期直接保持其三个数值。任务查询按三个字段相等匹配，不把日历日重新解释为 UTC 时间点。

界面回滚规则：创建失败时保留草稿；完成状态保存失败时恢复 checkbox 和原排序；删除失败时恢复任务行且不显示撤销提示；撤销失败时保持删除结果，并把撤销提示替换为带“重试”的错误提示。

## 7. 错误与恢复

- SwiftData 容器初始化失败：显示阻塞错误窗口，说明应用无法访问本地数据，并提供重新打开应用的操作。
- 查询失败：若该日期存在本次运行期间的最后成功结果，则继续显示缓存并标注“任务可能不是最新”，提供“重试”；若没有缓存，则任务区域显示“无法读取任务”和“重试”，绝不显示其他日期的数据。
- 单次保存失败：保留或恢复操作前状态，在面板底部显示具体错误和“重试”。
- 快捷键注册失败：菜单栏入口继续可用，并说明可能存在快捷键冲突。
- 快捷键注册失败时，右键菜单中的状态项显示“Control + Space 不可用”；左键打开面板和右键退出应用不受影响。
- 日期选择取消：保留当前日期，不改变任务筛选。
- 空标题：不创建任务，不显示错误弹窗。

## 8. 技术方案

- Swift 6、SwiftUI、AppKit、SwiftData。
- 最低系统版本 macOS 14。
- 使用 Swift Package Manager 管理源码与测试；构建脚本生成可双击运行的 `.app` 包。
- `LSUIElement = true`，默认不显示 Dock 图标。
- 不引入第三方依赖。

## 9. 验证计划

### 自动测试

- 日期规范化：今天、明天、跨月、夏令时边界。
- 输入校验：空白、首尾空格、500 字符上限。
- 排序：未完成在前；完成后移动；恢复后回到未完成组。
- Repository：创建、查询、完成、恢复、删除和撤销，使用内存 SwiftData 容器。
- 快捷键事件到面板显示状态的映射。

### 构建与人工验收

- Debug 和 Release 构建通过。
- 按 `Control + Space` 在不同应用和不同 Space 中唤出、隐藏。
- 点击菜单栏图标可作为快捷键失败时的备用入口。
- 验证输入焦点、回车添加、日期切换、checkbox、删除和撤销。
- 退出再启动，检查任务与完成状态保留。
- 验证空状态、超长任务、VoiceOver 名称和减少动态效果设置。

## 10. 验收标准

- 全局快捷键固定为 `Control + Space`。
- 核心操作在一个悬浮面板内完成，不打开独立主窗口。
- 所有任务均有 checkbox；完成后整行删除线并置灰。
- 日期选择最多一次点击进入系统日期选择器。
- 本地数据在正常退出和重新启动后保持一致。
- 首版不请求网络、日历、提醒事项或辅助功能权限。
