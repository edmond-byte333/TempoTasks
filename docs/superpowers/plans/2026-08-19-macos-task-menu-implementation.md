# TempoTasks 实施计划

## 目标

交付一个 macOS 14+ 原生菜单栏任务管理应用：`Control + Space` 唤出悬浮面板，支持按日期快速添加任务、完成/恢复、删除/撤销和本地持久化。

## 阶段 1：工程骨架与日期模型

1. 创建 Swift Package 可执行目标与测试目标。
2. 实现 `LocalDay`，覆盖今天、明天、跨月、时区稳定和日期格式化。
3. 定义 SwiftData `TaskItem` 与可恢复的 `TaskSnapshot`。
4. 编写日期和输入校验测试。

验收：`swift test` 通过，`LocalDay` 不因时区重新解释而改变年月日。

## 阶段 2：本地数据层

1. 定义 `TaskRepository` 协议。
2. 实现 SwiftData 查询、创建、完成/恢复、删除和完整快照恢复。
3. 实现稳定排序：未完成在前、完成时间排序、UUID 次级排序。
4. 为内存容器编写 CRUD、回滚、撤销与查询失败相关测试。

验收：Repository 测试覆盖所有操作和失败路径。

## 阶段 3：应用外壳

1. 实现 `GlobalHotKeyRegistrar`，注册 `Control + Space`。
2. 实现 `PanelController`：创建无标题浮动 `NSPanel`、当前屏幕顶部居中、即时显示/隐藏。
3. 实现菜单栏图标：左键切换面板，右键显示打开、快捷键状态和退出菜单。
4. 设置 agent 应用为 `LSUIElement`，不显示 Dock 图标。

验收：应用可启动，菜单栏入口和快捷键均可打开同一面板，Escape 与失焦隐藏。

## 阶段 4：业务状态与 SwiftUI 界面

1. 实现 `TaskPanelViewModel`：语义日期状态、草稿、查询缓存、错误与撤销窗口。
2. 实现深色 B 方向界面：日期轨道、快速输入、任务列表、空态、错误态和撤销提示。
3. 实现 checkbox 完成态的整行删除线与置灰。
4. 实现悬停删除、VoiceOver 标签、键盘焦点和超长标题提示。
5. 对照 `DESIGN.md` 落地至少 5 项工艺细节。

验收：功能契约在一个面板中完整可用，所有状态都有恢复路径。

## 阶段 5：打包、自动验证与两轮视觉验收

1. 编写 `scripts/build-app.sh`，生成 `build/TempoTasks.app`。
2. 运行 `swift test`、Debug 和 Release 构建。
3. 第一轮启动真实 App 并截图，从艺术总监、工程师、甲方、读者四个视角各找至少一项问题。
4. 第二轮仅修复 3–5 个最高影响问题，再次截图。
5. 完成快捷键、日期、添加、完成/恢复、删除/撤销和重启持久化人工验收。
6. 运行最终 preflight，记录已知限制。

验收：`.app` 可双击运行，测试与构建通过，核心交互经真实应用验证。
