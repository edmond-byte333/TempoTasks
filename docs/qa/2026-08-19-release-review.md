# TempoTasks 1.0 发布检查

## 第一轮原生界面检查

- 设计视角：核心记忆点为深色指令面板、珊瑚红完成标记和蓝色输入焦点；未发现左侧装饰色条或非必要渐变。
- 工程视角：自定义日期使用 popover 时，父面板可能因失去 key window 而被误隐藏。
- 使用视角：3 秒内可识别输入区、日期选择和 checkbox；但侧栏底部“今日进度”在查看其他日期时语义错误。
- 阅读视角：主标题、输入框、任务正文层级明确；次级信息保持低对比但可辨认。

修正项：

1. 面板仅在应用失活时隐藏，允许日期 popover 保持打开。
2. “今日进度”改为不依赖当前日期的“完成进度”。
3. 右键菜单的“打开 TempoTasks”始终打开面板，不再复用切换操作。

## 第二轮原生界面检查

- 自定义日期 popover 可保持显示，并可通过键盘选择 8 月 21 日。
- 回车添加任务后，输入框清空且所选日期保持不变。
- checkbox 可完成和恢复任务；完成后标题删除线、整行文字置灰、计数和进度同步更新。
- 删除后任务立即移除，并出现 5 秒撤销入口。
- 空状态、任务状态和完成状态均无布局跳动。

## 发布前检查

- `Control + Space` Carbon 注册探针：可用。
- 本地持久化：关闭并重建 SwiftData 容器后任务仍可读取。
- 自动化测试：10 项通过（7 项 XCTest，3 项 Swift Testing）。
- Release 构建、Info.plist 校验和 ad-hoc 签名校验：通过。
- 无 Apple Calendar / Reminders / 网络依赖。

## 窗口位置回归修复

- 复现：拖动 begin/end 回调执行时，`performDrag` 尚未发布最终窗口坐标，导致 frame 未变化且不会写入会话位置。
- 修复：使用 `windowDidMove` 捕获实际移动后的坐标；程序化默认定位通过独立标记排除。
- 坐标验证：默认 `(644, 538)`，移动后 `(764, 448)`，隐藏并重显仍为 `(764, 448)`。
- 重启验证：新进程恢复 `(644, 538)`，会话位置为空。
